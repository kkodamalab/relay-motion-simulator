# Relay Motion Simulator

[公開アプリ](https://kkodamalab.github.io/relay-motion-simulator/)

単独走行の四肢間協調と、二者間の周期・位相・相対運動を探索する側面2D運動学モデル。TWO RUNNERSでBATON EXCHANGEを外すと、腕の伸展と受け渡し判定を停止し、通常走行の二者を比較できる。

## モデル v2.0

走路右方向を +x、鉛直上を +y とする。位置は m、時間は s。ピッチは左右合計の歩/s、ストライド周波数はピッチ/2 Hz。同じ足の接地間隔を1周期とし、最初の30%を接地、残りを遊脚と規定する。左右位相差が180°以外の場合、左右交互の実際のステップ間隔は等間隔にならない。

骨盤高は平均0.765 mの余弦波で、ストライドあたり2回上下する。振幅ゼロも設定可能。支持期の足首は世界座標の接地点を目標とし、可動域付近で滑らかに飽和する。遊脚は連続補間で次の接地点に向かう。足首と骨盤から逆運動学で膝・股角を求め、各リンクは0.45 mを保つ。前後振幅・屈曲設定は足先経路を調節する入力であり、解析・出力は得られた関節角を使う。肩・股角は下向き鉛直から前方が正、肘・膝は屈曲が正、足関節角は下腿に対する足部方向。

## 位相と観察

脚の設定位相は同脚の接地で0°。腕は上腕角を生成する振動子位相を使う。相対位相は「後者−前者」を [−180°, 180°) に折り返す。波形推定位相は股・肩関節の角度から算出する。6秒間の60 Hz標本の最大・最小の中点を角度から引き、角速度を各肢の角周波数で割って atan2(中心化角度, 正規化角速度) を評価する。角速度は0.1 ms差分。位相平面の原点は未定義扱い。非正弦波や受け渡しの伸展中は位相指標の解釈に注意を要する。

PHASEで対象、変数、位相の種類、肢の組を選ぶ。二者の固定位相差は左脚基準で、周期一致も課す。同期は外部から与えた制御条件で、自発的な引き込みを推定しない。BODY RELATIVE軌跡は各時刻の骨盤を引いてから表示時刻の骨盤に重ねる。

## バトン

Aの左手が後端を保持し、接近時にB右手へ向ける。時刻窓、ゾーン、先端距離、手と骨盤の相対速度、Bの把持点がバトンの線分上にあることを120 Hzで検査する。成功後0.24秒間で把持位置を後端から長さの8%の位置へ滑らかに移す。Bの手は移行中もバトン上にあり、長さは一定。成立条件に位相同期は含まれない。

## 再生・出力・制限

試技は6秒。任意時刻から直接計算し、再生倍率は表示時間にのみ作用する。自動スローは成功の0.4秒前から0.15秒後まで最大0.25倍。イベント前後1秒はA–Bループの初期区間。CSV・JSONは同じ120 Hz標本を使い、接地・離地の列には直前の標本以後に発生したイベントの解析時刻を記録する。

接地は規定した運動学イベント。可動域を超える速度・周期条件で足滑りが残る。床反力、把持力、衝突、筋活動、転倒・落下は予測しない。

## 開発

Node.js 24。npm ci、npm run dev で起動。npm test、npm run build、npx playwright install chromium、npm run e2e で検証する。TEST_URLを設定すると公開サイトに対してPlaywrightを実行する。接地前後・移管後のスクリーンショットはPlaywrightのtest-results内に出力する。
