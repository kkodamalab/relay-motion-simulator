# Relay Motion Simulator

[GitHub Pages](https://kkodamalab.github.io/relay-motion-simulator/)

TypeScript + Vite による、単独走行と2名のバトンパスの側面運動学シミュレーター。青が渡し手、橙が受け手。左肢は実線、右肢は半透明の破線。

## 起動・検証

Node.js 24 で npm ci、npm run dev を実行。npm test でモデルを検証し、npx playwright install chromium の後、npm run e2e でブラウザを検証する。npm run build の成果物は dist に生成される。公開サイトに対しては TEST_URL に末尾スラッシュを含む URL を指定して npm run e2e を実行できる。

## モデルと操作

6秒の試技を任意時刻で直接評価する。一定加速度モデルは最高速度または速度ゼロに達すると等速に移行する。ピッチは左右合計の歩数/秒。肩・股角は下向き鉛直から前方が正、肘・膝は屈曲が正、足関節角は下腿に対する足部方向。接地付近では足関節の走路方向位置を補正する。振幅・リンク長の制約で足滑りは残り得る。

渡し手の左手から前方へ水平にバトンを配置し、受け手の右手と先端の距離、先端と右手の相対速度（1/120秒の後退差分）、骨盤の相対速度、ゾーン、伸展時間窓を毎秒120回評価する。両者の伸展開始から保持終了までの重複時間内で最初に全条件が成立した標本を成功とする。移管時の先端と手の相対位置を維持する。成立せず試行窓が閉じると失敗となる。接触力、把持力、落下は扱わない。

設定変更は現在時刻を維持して試技全体を再計算する。RESETは全設定と時刻を初期化する。グラフの系列は60 Hz、イベント判定とCSV/JSON出力は120 Hz。アニメーションと現在値は表示時刻で直接評価する。直前・直後ボタンはイベントの前後0.1秒。A–B区間の初期値はイベント前後1秒を試技内に収めた範囲。
